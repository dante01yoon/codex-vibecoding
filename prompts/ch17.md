# 챕터 17 오픈 API와 웹 크롤링으로 외부 데이터 활용하기

## [바이브 코딩 15] 스트림릿 라이브러리로 영화 박스오피스 대시보드 만들기

**프롬프트 1**

```text
파이썬의 Streamlit 라이브러리를 사용해서 '영화 박스오피스 대시보드'를 만들어줘. 사용자에게 날짜를 입력받아서 영화진흥위원회 API로 해당 날짜의 박스오피스 데이터를 가져와줘. 그리고 1위~10위 영화의 관객 수를 막대그래프로 시각화하고, 아래에는 상세 데이터를 표로 보여줘. uv 패키지 매니저를 사용하면 좋겠어.
```

**프롬프트 2**

```text
만든 코드를 파이썬 입문자도 쉽게 실행할 수 있도록 상세한 가이드를 README.md 파일에 작성해줘.
```

**명령어**

```bash
uv run streamlit run app.py
```

## [바이브 코딩 16] 실시간 주식 대시보드 만들기

**프롬프트 1**

```text
Playwright MCP를 사용해서 주식 시장 데이터를 크롤링해오고 Streamlit으로 시각화하는 대시보드를 만들거야. memory-bank를 사용하고 이를 업데이트한다는 내용을 AGENTS.md에 작성해줘. 그리고 이를 위한 PRD를 memory-bank에 만들어줘. 주가 데이터는 트레이딩뷰의 데이터를 사용할 거야. 거래량 상위 50개 기업 주식의 현재가와 전일 대비 등락률을 크롤링해서 가져와야 해.
```

**프롬프트 2**

```text
PRD를 참고하여 기능 구현을 시작해.
```

**프롬프트 3**

```text
프로젝트 정보 및 실행 가이드를 README.md 파일에 작성해줘.
```

**프롬프트 4**

```text
방금 만든 코드에 기능을 더 추가하고 싶어. 4가지 요구 사항을 추가로 구현하기 위한 PRD를 작성하고 memory-bank 폴더에 구현 계획을 작성해줘.
```

**프롬프트 5**

```text
업데이트된 PRD를 기반으로 실제 구현을 시작해.
```

**프롬프트 6**

```text
트레이딩뷰 티커/뉴스 페이지를 사용해줘.
```

**명령어**

```bash
npm run crawl
```
