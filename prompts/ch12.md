# 챕터 12 내 웹사이트 인터넷에 배포하기

## [바이브 코딩 10] 깃허브 페이지로 블로그 배포하기

**프롬프트 1**

```text
깃허브 페이지로 배포할 수 있도록 배포 환경을 구축해줘. 나는 'deploy' 브랜치를 사용해 배포할 거고, 깃허브 액션을 사용하고 싶어.
```

**명령어**

```bash
git checkout -b deploy
git push --set-upstream origin deploy
git push
```

## [바이브 코딩 11] 버셀로 블로그 배포하기

**프롬프트 1**

```text
vercel 배포를 위한 배포 환경을 설정해줘.
```

**명령어**

```bash
git checkout -b vercel
vercel
git push
```
