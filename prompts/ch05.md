# 챕터 05 코덱스 CLI 고급 사용법 알아보기

## 오픈라우터를 사용해 다른 모델 제공자의 AI 모델 사용하기

**코드 (config.toml)**

```toml
model="google/gemini-2.5-pro" # 단계 05에서 복사해 두었던 모델 정보를 입력합니다
model_provider = "openrouter" # model_provider의 값으로 model_providers.openrouter와 동일하게 기입합니다
[model_providers.openrouter]
name = "OpenRouter"  # 모델 제공자의 이름을 입력합니다
base_url = "https://openrouter.ai/api/v1" # base_url의 엔드포인트인 주소를 기입합니다
env_key = "OPEN_ROUTER_API_KEY"
```

> 참고: 책의 `env_key` 값(`OPEN_ROUTER_API_KEY`)과 아래 `export` 명령의 변수 이름(`OPENROUTER_API_KEY`)이 다릅니다. 둘 중 하나로 이름을 맞춰야 키를 읽습니다.

**프롬프트 1**

```text
너는 누구야?
```

**명령어**

```bash
echo $SHELL
echo 'export OPENROUTER_API_KEY="your-api-key-here"' >> ~/.zshrc
echo 'export OPENROUTER_API_KEY="your-api-key-here"' >> ~/.bash_profile
```

## 멀티 프로필 생성하기

**코드 (config.toml)**

```toml
[profiles.gemini] # 프로필 테이블을 작성하세요
model="google/gemini-2.5-pro" # gemini 프로필에서는 google/gemini-2.5-pro 모델을 입력하세요
model_provider = "openrouter" # 모델 제공자는 앞서 사용했던 오픈라우터를 그대로 사용합니다
```

**코드 (config.toml)**

```toml
[profiles.opus]
model="anthropic/claude-opus-4.1"
model_provider = "openrouter"
```

**명령어**

```bash
codex --profile [프로필 이름]
codex --profile opus
```

## 사용자 정의 형식으로 응답 출력하기

**코드**

```json
{
 "type": "object",
 "properties": {
   "status": { "type": "string", "enum": ["success", "needs_follow_up"] },
   "summary": { "type": "string" },
   "next_steps": {
     "type": "array",
     "items": { "type": "string" }
   }
 },
 "required": ["status", "summary", "next_steps"],
 "additionalProperties": false
}
```

**명령어**

```bash
codex exec \
  --output-schema schema.json \
  "다이어트를 하려면 어떤 준비 과정을 거쳐야 해?"
```

## [바이브 코딩 04] 3D 레이싱 게임 만들기

**프롬프트 1**

```text
3D 레이싱 게임을 만들건데, 작업에 들어가기 전에 사용할 언어와 프레임워크를 나열해서 내가 선택할 수 있게 해줘
```

**프롬프트 2**

```text
Three.js로 만들어줘
```

**프롬프트 3**

```text
지금 다음과 같은 문제가 있어
1. A 키를 눌렀을 때는 왼쪽이 아닌 오른쪽 방향으로, D 키를 눌렀을 때는 오른쪽이 아닌 왼쪽 방향으로 이동합니다.
2. W 키를 눌렀을 때는 앞으로 가고 S 키를 눌렀을 때는 뒤로 갑니다.
3. 길을 벗어나도 아무런 제약 사항이 없습니다. 속도가 느려져야 합니다.
4. 현재 맵이 너무 작아요. 실제 레이싱 게임만큼 맵을 더 현실적으로 만들어야 해요.
```

**프롬프트 4**

```text
다음 요구사항을 수행해 주세요.
1. 좌우 방향 전환을 조금 더 어렵게 하여 실제 운전하는 것처럼 생동감 넘치게
2. 경쟁자들을 만들고 AI 자동차의 속도가 조금은 불규칙하게, 중간선만 따라 가지 말고 실제 드라이빙하는 것처럼
3. 현재 내 위치를 알 수 있는 미니맵을 그려줘
```

**프롬프트 5**

```text
다음 요구사항을 수행해 주세요.
1. 실제 길처럼 가로수나 전등, 장애물을 추가
2. 컨트리뷰터가 커스텀 맵을 추가할 수 있도록 게임의 맵을 별도 모듈로 분리하고, 게임 시작할 때 맵을 선택할 수 있도록
3. 체크포인트를 통과할 때마다 HUD 말고 실제 화면에 점수가 플러스되는 애니메이션을 보여줘서 심미성을 추가
4. 자동차의 모습을 더 실제 F1 레이싱카처럼 만들어줘.
```

**명령어**

```bash
npm install
npm run dev
```
