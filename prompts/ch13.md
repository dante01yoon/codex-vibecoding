# 챕터 13 클라우드 데이터베이스 사용하기

## 수파베이스 MCP로 코덱스와 내 코드 연결하기

**프롬프트 1**

```text
Context7 MCP 호출해서 수파베이스 MCP를 .codex/config.toml 파일에 연동하는 방법을 한글로 알려줘.
```

**프롬프트 2**

```text
수파베이스 MCP 서버가 동작하는지 확인하고 사용 가능한 tool 리스트를 알려줘.
```

## MCP로 쉽게 데이터 관리하기

**프롬프트 1**

```text
수파베이스 MCP를 사용해 'guestbook' 테이블에서 모든 데이터를 가져와줘.
```

**프롬프트 2**

```text
수파베이스 MCP를 사용해 'guestbook' 테이블에 작성자는 '단테', 내용은 '첫 방문입니다!'인 새로운 데이터를 추가해줘.
```

**프롬프트 3**

```text
수파베이스 MCP를 사용해 'guestbook' 테이블에서 id가 1인 데이터의 내용을 '반갑습니다!'로 수정해줘.
```

**프롬프트 4**

```text
수파베이스 MCP를 사용해 'guestbook' 테이블에서 id가 1인 데이터를 삭제해줘.
```

## [바이브 코딩 12] 수파베이스로 실시간 방명록 웹사이트 만들기

**프롬프트 1**

```text
실시간 전자 방명록을 만들고 싶어.
1. 첫 화면에서는 사진 첨부 혹은 사용자가 그림을 그려 등록하면
2. 두 번째 페이지에서 사람이 남긴 글자와 사진이 포스트잇처럼 붙여지고
3. 각 포스트잇을 클릭하면 그림과 사람들의 댓글이 새로고침을 하지 않아도 실시간으로 업데이트되어야 해.
이 앱을 만들기 위한 프롬프트 초안을 작성해줘.
```

**프롬프트 2**

```text
수파베이스 환경 변수가 설정되지 않았다고 오류 문구가 보여. 어떻게 수정해야 해?
```

**프롬프트 3**

```text
{"statusCode":"404","error":"Bucket not found","message":"Bucket not found"} 이건 어떻게 해결해야 해?
```

**프롬프트 4**

```text
{code: 'PGRST205', details: null, hint: null, message: "Could not find the table 'public.entries' in the schema cache"} 이게 무슨 오류인지 알려줘. 그리고 현재 코드 상에서 사진이 업로드되었는지 추론해줘.
```

**프롬프트 5**

```text
새로고침하지 않더라도 실시간으로 다른 사용자가 등록한 댓글을 확인하려면 어떻게 하면 돼?
```

**명령어**

```bash
git fetch --all
npm install
npm run dev
```
