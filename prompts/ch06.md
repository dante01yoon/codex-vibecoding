## [바이브 코딩 05] 미니멀리즘 감성 일기장 만들기

**코드 (AGENTS.md)**

```markdown
# 프로젝트 가이드라인: 미니멀리즘 감성 일기장 (Vibe Diary)
## 1. 프로젝트 개요
- 이 프로젝트는 사용자의 감정에 따라 UI가 동적으로 변하는 미니멀한 웹 일기장입니다.
- 핵심 가치는 '단순함'과 '감성적 경험'입니다. 모든 기능은 이 원칙을 따라야 합니다.
- 데이터는 서버 없이 `localStorage`에만 저장합니다.
## 2. 디자인 시스템
- 아이콘 라이브러리: `Feather Icons`만 사용해주세요. 아이콘 크기는 24px을 기본으로 합니다.
- 폰트: 'Pretendard' 웹 폰트를 사용해주세요. 본문 16px, 날짜 14px 입니다.
- 애니메이션: 모든 색상 및 테마 변경은 `transition: all 0.5s ease-in-out;` CSS 속성을 적용해 부드럽게 표현해주세요.
## 3. 감정 테마 규칙 (매우 중요!)
- 사용자가 감정을 선택하면, 다음 규칙에 따라 앱 전체의 배경색과 텍스트 색상을 변경해야 합니다.
 - `happy`: 배경 `#FFFBEB`, 텍스트 `#F59E0B`
 - `sad`: 배경 `#EFF6FF`, 텍스트 `#3B82F6`
 - `calm`: 배경 `#F0FDF4`, 텍스트 `#16A34A`
 - `angry`: 배경 `#FEF2F2`, 텍스트 `#EF4444`
 - `neutral`: 배경 `#F9FAFB`, 텍스트 `#6B7280`
## 4. 컴포넌트 구조
- `src/components/` 폴더에 컴포넌트를 만들어주세요.
- `EmotionPicker.tsx`: 5개의 감정 아이콘을 표시하고 선택 이벤트를 처리합니다.
- `DiaryEditor.tsx`: 날짜 표시, `EmotionPicker`, 텍스트 입력을 포함하는 메인 편집기입니다.
- `HistoryList.tsx`: 과거 일기 목록을 표시하는 컴포넌트입니다.
## 5. 데이터 구조
- `localStorage`에 `vibeDiaryData` 라는 키로 데이터를 저장해주세요.
- 자료형식은 다음과 같은 객체 배열입니다.
  `{ id: "YYYY-MM-DD", date: number, emotion: string, text: string }`
- 일기는 300ms `debounce`를 적용해 자동 저장해주세요.
```

**프롬프트 1**

```text
미니멀리즘 감성 일기장 프로젝트를 생성해줘. 프로젝트의 콘셉트는 "하루의 끝, 오직 당신의 감정과 생각에만 집중하는 공간." 복잡한 기능과 불필요한 장식을 모두 걷어내고, 사용자가 그날의 감정을 선택하고 짧은 글을 남기는 핵심 경험에만 집중한다. 핵심 가치는 미니멀리즘, 감성적 경험, 직관성이다. 텍스트를 입력하여 오늘의 생각을 기록할 수 있다. 내 일기는 별도의 저장 버튼 없이 자동으로 저장해야 하며, 과거 일기 조회가 가능해야 하고 목록에서 각 일기의 날짜, 감정 아이콘, 그리고 내용의 일부를 미리 볼 수 있다. 목록에서 특정 일기를 선택하면, 전체 내용을 읽을 수 있다.
```

## [바이브 코딩 06] 마크다운 HTML 변환기

**코드**

```markdown
# 안녕하세요!
이것은 마크다운을 HTML로 변환하는 테스트입니다.
## 주요 기능
- 마크다운 문법 지원
- HTML 파일 생성
잘 변환되는지 확인해봅시다
```

**프롬프트 1**

```text
프롬프트 제너레이터 역할을 해줘.  나는 마크다운을 HTML로 변경하는 파이썬으로 작성한 트랜스포머 스크립트를 만들고 싶어. 내가 프롬프트 제너레이터에게 어떤 사항을 제시해줘야 프롬프트 엔지니어링을 준수하는 프롬프트를 만들어줄 확률이 높을까?
```

**프롬프트 2**

```text
좋아, 이걸 그대로 입력으로 사용해서 프롬프트 엔지니어링을 준수하는 프롬프트를 만들어줘. 프롬프트는 다음과 같은 사항을 준수해야 해
1. 명확하고 구체적으로 이야기하기: 컨텍스트 구성하기
2. 페르소나 지정하기 (역할 지정하기)
```
