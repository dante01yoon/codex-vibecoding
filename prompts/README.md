# 「요즘 바이브 코딩 코덱스 완벽 가이드」 프롬프트·명령어 모음

책에 나온 프롬프트와 명령어, 설정 코드를 챕터별로 모았습니다. 직접 입력하지 않고 복사해서 쓸 수 있습니다.

- **프롬프트**: 코덱스 입력창에 붙여 넣습니다. `[대괄호]`나 `{중괄호}` 부분은 자기 값으로 바꿔 쓰세요.
- **명령어**: 터미널에 한 줄씩 입력합니다. 코덱스 안에서 쓰는 `/`로 시작하는 명령(예: `/compact`)은 코덱스 입력창에 입력합니다.
- **코드**: 설정 파일(`config.toml`, `AGENTS.md` 등)에 넣는 내용입니다.

코덱스는 같은 프롬프트에도 매번 조금씩 다른 결과를 냅니다. 책의 화면과 결과가 달라도 정상입니다.
