## [바이브 코딩 07] 깃허브 MCP 사용하여 내 작업 사항 저장하기

**코드 (config.toml)**

```toml
[mcp_servers.github]
command = "docker"
args = [
  "run",
  "-i",
  "--rm",
  "-e",
  "GITHUB_PERSONAL_ACCESS_TOKEN", // ➊
  "ghcr.io/github/github-mcp-server"
]
[mcp_servers.github.env] // ➋
GITHUB_PERSONAL_ACCESS_TOKEN = "[발급받은 깃허브 토큰]"
```

**프롬프트 1**

```text
깃허브 MCP를 사용해 "codex-markdown-converter-new" 저장소를 생성해줘
```

**프롬프트 2**

```text
지금 폴더에 있는 작업 사항을 깃허브에 올려주세요. 이때 업로드가 불필요한 파일은 .gitignore 파일을 만들어 생략하세요.
```

**프롬프트 3**

```text
깃허브 MCP를 사용해 변경 사항을 푸시(push)해줘.
```
