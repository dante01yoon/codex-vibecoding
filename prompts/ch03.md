## config.toml 파일과 코덱스 CLI

**코드**

```toml
# 이 코드 라인은 주석을 작성한 겁니다. 주석은 읽는 사람에게 부가적인 정보를 전달하기 위함이며 프로그램에
# 영향을 미치지 않습니다
title = "My App" # ➊
debug = true
retries = 3
[server] # ➋ 대괄호는 테이블이라고 부릅니다. 하나의 섹션을 만드는 데 사용합니다
host = "0.0.0.0"
port = 8080
[[users]] # ➌ 대괄호 두 개는 섹션의 리스트를 만들 때 사용합니다.
name = "Dante"
role = "admin"
[[users]] # users 섹션에 또 다른 엔트리인 Bob을 만들었습니다
name = "Bob"
role = "viewer"
```

**코드 (config.toml)**

```toml
model = "gpt-5-codex" # ➊
model_reasoning_effort = "high" # ➋
[projects."/Users/dante/Desktop/codex-project/toml-example"] # ➌
trust_level = "trusted" # ➍
```

## [바이브 코딩 02] 작업이 끝나면 알려주는 나만의 알림창 만들기

**프롬프트 1**

```text
코덱스 CLI 응답이 완료된 후 커스텀 알림을 실행하기 위한 기본적인 파이썬 스크립트를 codex_emoji_notify.py라는 이름으로 작성해줘
```

**코드**

```python
def build_notification(notification: dict[str, Any]) -> tuple[str, str, str, str | None] | None:
   notification_type = notification.get("type")
   if notification_type != "agent-turn-complete":
       printf("not sending a push notification for: {notification_type}")
       return None
```

**코드 (config.toml)**

```toml
model = "gpt-5-codex"
model_reasoning_effort = "high"
search = true
notify = ["python3", "codex_emoji_notify.py"] # 파이썬 스크립트를 실행합니다
```

**코드**

```json
{
  "type": "agent-turn-complete", ➋
  "turn-id": "12345",
  "input-messages": ["Rename `foo` to `bar` and update the callsites."],
  "last-assistant-message": "Rename complete and verified `cargo build` succeeds."
}
```
