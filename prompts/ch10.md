# 챕터 10 바이브 코딩을 위한 기초 개발 지식 다지기

## [바이브 코딩 08] 오델로 게임 만들기

**프롬프트 1**

```text
이 오델로 게임을 만들기 위한 기술 스택을 AGENTS.md 파일에 만들어줘. HTML, CSS, 자바스크립트를 사용하고 리액트 컴포넌트를 이용해 구동해야 해. 유지보수가 가능하도록 최적화된 개발 구조에 대한 규칙을 작성해줘.
```

**프롬프트 2**

```text
game-design-document.md를 읽고, 구체적인 구현 계획을 implementation-plan.md에 작성해줘.
```

**프롬프트 3**

```text
/memory-bank 디렉터리 내 모든 문서를 읽고, 구현 계획의 1단계를 진행해줘. 테스트는 내가 직접 수행할 건데 테스트를 검증하기 전까지는 2단계를 시작하지 마. 테스트를 검증한 후에는 progress.md 파일을 열어 향후 개발자들을 위해 수행한 작업을 문서화해줘. 그런 다음 각 파일의 역할을 설명하기 위해 architecture.md 파일에 아키텍처 관련 통찰력을 추가해줘.
```

**프롬프트 4**

```text
다시 memory-bank 폴더의 모든 파일과 progress.md를 읽어 기존 작업을 이해한 후 2단계를 진행해줘. 테스트를 내가 직접 검증하기 전까지는 3단계를 시작하지 마.
```
