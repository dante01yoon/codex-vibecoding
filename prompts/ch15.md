# 챕터 15 PRD로 명확한 방향 제시하기

## PRD 작성하기

책에서 사용자 프로필 기능을 예로 쓴 PRD입니다. `memory-bank/prd-user-profile.md`처럼 memory-bank 폴더에 저장해 사용합니다.

**코드 (memory-bank/prd-user-profile.md)**

```markdown
# 사용자 프로필 설정 기능 PRD

1. 목표와 기능 정의 : 사용자 프로필 설정 기능을 만듭니다. 사용자가 자신의 정체성을 표현할 수 있도록 자신만의 닉네임과 사진을 가진 사용자로 활동하게 하여 누가 글을 썼는지 한눈에 알 수 있게 합니다.
2. 사용자 스토리 :
   a. As a(사용자로서) : 타깃 사용자는 회원가입을 완료한 사용자로서
   b. I want to (나는 ~을 하고 싶다) : 나를 표현하는 닉네임과 프로필 사진을 등록하고 싶다.
   c. So that (그러면 ~할 수 있다) : 다른 사람들이 방명록에서 나를 쉽게 알아보고 기억해줄 수 있다.
3. 기능 요구 사항 : 여기에는 필수 구현 사항과 권장 사항을 명시합니다.
   a. P0(필수 요구 사항)
      i. 프로필 페이지 진입 : 로그인한 사용자는 자신의 프로필 설정 페이지로 이동할 수 있어야 한다.
      ii. 닉네임 변경: 기본적으로 이메일 아이디가 아닌 원하는 닉네임으로 변경하고 저장할 수 있어야 한다.
      iii. 프로필 사진 업로드 : PC나 모바일에서 이미지를 선택해 프로필 사진으로 업로드할 수 있어야 한다.
      iv. 방명록 반영 : 방명록 글 목록과 상세 화면에서 작성자의 닉네임과 사진이 보여야 한다.
      v. 자동 생성 : 회원가입 시 별도 설정 없이도 프로필 데이터(기본값)가 자동으로 생성되어야 한다.
   b. P1(권장 요구 사항)
      i. 닉네임 중복 방지 : 다른 사람과 똑같은 닉네임은 사용할 수 없게 막는다.
      ii. 이미지 용량 제한 : 너무 큰 사진(5MB 이상)은 업로드되지 않도록 막는다.
```
